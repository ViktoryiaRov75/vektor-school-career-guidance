# Вектор — профориентация в школе

Откройте `index.html` в современном браузере. Это локальный **демонстрационный прототип**, без сервера и установки. В правом верхнем углу можно переключать роли: администрация, педагог-профориентолог, ученик, родитель. В ролях ученика и родителя там же выбирается демонстрационный профиль ребенка.

## Возможности

- **Администрация:** сводка, поименный отчет с четырьмя сигналами, справочники направлений и профессий, ссылки на видео, загрузка итоговых годовых оценок и требований к предметам, PDF через системное окно печати («Сохранить как PDF»).
- **Профориентолог:** статусы профпроб «успешно / неуспешно», автоматически предложенные и редактируемые заключения. Сохраненное заключение сразу видно ученику и родителю.
- **Ученик:** свои оценки, интересы, выбор профессии, результаты профпроб, отзыв о пробе, заключение и видеотека.
- **Родитель:** только просмотр данных своего ребенка, включая интересы, отзывы и заключение.

Сигналы появляются, если: профессия не связана с указанными интересами; профпроба по направлению профессии неуспешна; успешная профпроба относится к другому направлению; итоговая оценка **3 или ниже** по приоритетному предмету профессии. Отсутствие данных не трактуется как отрицательный результат. Учебные заведения не предлагаются и не отображаются: их требования используются только для списка приоритетных предметов профессии.

## Формат импорта

Файлы CSV в UTF-8 с разделителем `;`. Заголовки должны совпадать с примерами. Можно использовать кавычки вокруг ячеек и переводы строк внутри кавычек.

Итоговые годовые оценки (пустые ячейки не меняют сохраненные оценки, выпускники сопоставляются по имени и классу):

```csv
имя;класс;русский язык;математика;информатика;биология;обществознание
Анна Смирнова;11А;5;5;5;4;4
```

Требования к предметам (профессия должна уже быть в справочнике; несколько строк для одной профессии объединяются, а обновление заменяет прежний перечень именно для загруженных профессий):

```csv
профессия;предметы
Разработчик;Математика|Информатика
Врач;Биология|Русский язык
```

Формат интеграции со школьной системой пока неизвестен, поэтому реализована промежуточная загрузка CSV, а не прямое подключение. Демонстрационные предметы стартового справочника нужно заменить актуальной загрузкой перед использованием для анализа.

## Ограничение по безопасности

Роли в прототипе **не являются авторизацией**: переключатель доступен любому пользователю браузера, а все данные хранятся в `localStorage` только на этом устройстве. Не вводите реальные персональные данные учащихся. Для эксплуатации в школе необходимы серверное хранилище, аутентификация, разграничение доступа, резервное копирование и защищенная интеграция со школьной системой.

При первом запуске загружаются демонстрационные выпускники. Ранее сохраненные данные из первой версии прототипа переносятся, но старые числовые результаты профпроб не переводятся автоматически в статусы: их должен заново указать педагог-профориентолог.
